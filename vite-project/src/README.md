# Capital Apartments

## Overview

Capital Apartments is a React-based application designed to help admins manage apartment rentals efficiently. The application allows users to view, add, edit, and delete apartment listings.

## Features

- View a list of available apartments
- Add a new apartment listing
- Edit details of an existing apartment
- Delete an apartment listing
- View detailed information about a specific apartment
- Responsive design with a sidebar for navigation
